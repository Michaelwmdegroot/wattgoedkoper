# WattGoedkoper

Persoonlijk energie-inzicht voor Nederlandse huishoudens. Gratis scenarioanalyse voor verbruik, zonnepanelen, thuisbatterijen, isolatie en energiecontracten, met een optionele adviesaanvraag bij NIVO Groep Holland of Thuisbatterij Team.

De eerste release wordt gebouwd als lichte HTML/CSS/JavaScript/PHP-website voor directe deployment vanuit `main` op bestaande Hostinger-hosting. Berekeningen zijn indicatief, uitlegbaar en bronvermeld. Geen contactgegevens vereist om het plan te bekijken.

Status: ontwikkeling van de eerste werkende versie. Productiehost en leadopslag zijn nog niet geactiveerd.
